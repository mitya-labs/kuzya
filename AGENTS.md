# Правила для агентов

Наследует правила проекта skladenOS (`../skladenos/AGENTS.md`):

- Любой джоб (команда, сборка, скачивание, инференс, SSH) объявлять **до** запуска
  в формате `[~N мин/сек, HH:MM] что делаю`, время брать из `date +%H:%M`;
  для долгих (>1 мин) добавлять `→ ~HH:MM`. Если затянулось — сообщить и дать новую оценку.
- Статус — в `SUMMARY.md`, обновлять при значимых изменениях.
- Логи — в `logs/`.
- Долгие блокирующие команды запускать в фоне и упоминать это.
- Телефон: Poco F1, skladenOS, SSH по ключу: `ssh <user>@<phone-ip>`; реальные значения в `LOCAL.md` (не в git). В `AGENTS.md` skladenos пользователь указан как mobian — устарело.
- Перед работой с телефоном по SSH включать nosleep (`phone-nosleep on`), по окончании выключать.

## Язык документации
- Основной язык документации — английский. Новые и обновляемые документы писать на английском.
- Русский текст не удалять и не переводить принудительно: он остаётся наравне с английским.

## Специфика Кузи
- Новые инструменты добавлять только в `internal/tools/` (Go); всё, что меняет систему, помечать `Dangerous: true`.
- Не давать модели произвольный shell.
- Любое изменение промпта/инструментов проверять прогоном `tests/` и записывать долю верных вызовов в `SUMMARY.md`.
